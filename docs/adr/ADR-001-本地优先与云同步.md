# ADR-001 本地优先 + 云同步（暂缓启用）

- 状态：已接受（云同步部分暂缓）
- 日期：2026-09-10

## 背景
记账数据敏感、用户基数小、需要离线可用。规划中要求未来支持多端同步。

## 决策
- 数据以本地 SQLite（sql.js + Capacitor 持久化）为唯一事实来源，UI 永远先读写本地。
- 同步预留：transactions/categories/accounts 等表已带 `sync_status` / `version` / `client_id` 字段。
- 云同步本身暂缓，待「数据访问收口（ADR-005）」完成后启动。

## 后果
- 优点：离线可用、隐私好、无服务端依赖即可上线。
- 代价：多设备一致性缺失；同步启用前不能保证跨端数据。
- 启用条件：A-1 服务层稳定；具备冲突解决策略（见 ADR-003）。
