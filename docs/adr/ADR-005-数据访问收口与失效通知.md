# ADR-005 数据访问收口 + 失效通知

- 状态：已接受（本次落地）
- 日期：2026-09-10

## 背景
UI 曾直接调用 `getAppContext().xxxRepo`（39+ 处），导致：
写操作后其它页面不刷新，只能靠 `key` 重挂载；组件难以单测。

## 决策
- 新增 `src/data/services.ts`：按业务域包装仓库（transaction/category/account/budget/recurring/settings/stats），
  写方法执行后 `emit` 失效事件。
- 新增 `src/data/dataEvents.ts`：topic 级订阅/发布（transactions/accounts/categories/budgets/recurring/settings）。
- 新增 `useDataVersion(topic)`：页面订阅后重新加载自己的数据。
- UI 层禁止直接访问 AppContext；只有 `services.ts` 允许。

## 后果
- 优点：跨页数据自动一致；数据访问可替换、可 mock。
- 代价：多一层间接；需在新增数据操作时走 services 才能保持刷新语义。
- 验收：`grep -rn getAppContext src --include=*.tsx --include=*.ts | grep -v src/data/` 应为空。
